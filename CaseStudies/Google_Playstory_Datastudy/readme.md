  # 📱 Google Play Store Data Study

  This project analyzes Google Play Store data to uncover trends in categories, ratings, installs, and pricing.

  ---

  ## 📊 Overview
  - Understand factors influencing app success.
  - Dataset includes app details, ratings, installs, and prices.
  - Tools: Python, Pandas, Matplotlib, Seaborn.

  ---

  ## 🔍 Key Insights
  - 📈 Games and Productivity dominate installs.
  - ⭐ Higher ratings link to better retention.
  - 💵 Free apps gain more installs; paid apps show niche use.


  ---

  ## 📌 Future Scope
  - Add sentiment analysis from reviews.
  - Predict app success with machine learning.
