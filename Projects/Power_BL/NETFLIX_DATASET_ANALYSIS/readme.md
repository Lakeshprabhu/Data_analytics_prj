## 📌 Project Overview
This project analyzes the Netflix dataset to uncover trends and insights about movies and TV shows available on the platform. Using **Power BI**, interactive dashboards were created to visualize key metrics such as content distribution, trends over time, and genre popularity.

---

## 📂 Dataset
The dataset includes the following columns:
- **Title** – Name of the Movie/TV Show  
- **Type** – Movie or TV Show  
- **Director** and **Cast**  
- **Country** – Country of production  
- **Release Year** – Year of release  
- **Date Added** – Date added to Netflix  
- **Rating** – Content rating (e.g., PG, R)  
- **Duration** – Minutes for movies / Seasons for TV shows  
- **Genres/Categories** – Content classification  

Dataset source: [Netflix Shows Dataset (Kaggle)](https://www.kaggle.com/shivamb/netflix-shows)

---

## 🎯 Objectives
1. Compare the distribution of Movies vs TV Shows.  
2. Identify top countries contributing to Netflix content.  
3. Analyze trends in content releases over time.  
4. Explore popular genres and ratings distribution.  
5. Create an interactive dashboard to filter by year, type, and country.

---

## 🛠 Steps Performed
1. **Data Cleaning & Preparation**  
   - Removed duplicates and handled missing values.  
   - Standardized date formats.  
   - Extracted numerical values from duration (minutes, seasons).  

2. **Data Import in Power BI**  
   - Loaded dataset into Power BI (CSV/Excel).  
   - Transformed data using Power Query.  

3. **Dashboard Creation**  
   - Built visuals (cards, bar charts, line charts, maps).  
   - Created slicers for dynamic filtering.  
   - Designed KPIs to track growth and distribution.

---

## 📊 Dashboard Features
- **Content Overview**: Total titles, Movies vs TV Shows ratio.  
- **Geographical Insights**: Map visualization of top-producing countries.  
- **Time Trends**: Content releases over the years.  
- **Genre & Rating Analysis**: Popular genres and rating distribution.  
- **Interactive Filters**: Filter by Year, Country, and Content Type.

---

## 🧰 Tools Used
- **Power BI** – Visualization and dashboard creation.  
- **Power Query** – Data cleaning and transformation.  
- **Excel/CSV** – Dataset storage.

---

## 🚀 How to Use
1. Download the dataset from [Kaggle](https://www.kaggle.com/shivamb/netflix-shows).  
2. Open the `Netflix_Analysis.pbix` file in Power BI Desktop.  
3. Interact with filters and slicers to explore insights.
