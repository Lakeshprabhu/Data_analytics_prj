📊 Google & Facebook Ad Data Analysis
Overview

This project analyzes digital advertising performance data from Google Ads and Facebook Ads. The dataset provides insights into spending behavior, audience segmentation, campaign performance, and cost-efficiency across different channels, devices, and age groups.

📁 File Information

Filename: Ad-data-Assignment-1 (2).xlsx
Sheets Included:

Detail1 – Google Ads campaign-level data (spends, impressions, clicks, link clicks)

Detail2 – Facebook Ads campaign-level data (same structure as Google)

Subchannels – Summary of spends, impressions, clicks, CPC, and CPA by subchannel

Device_by_age – Cost metrics segmented by device type and age group

Ad-data-Assignment-1 – Combined dataset containing all campaigns

Dashboard – Visualization summary of performance indicators

🧠 Key Objectives

Compare Google Ads vs Facebook Ads efficiency.

Identify high-performing subchannels and audience segments.

Evaluate cost metrics like CPC (Cost per Click) and CPA (Cost per Acquisition).

Understand device- and age-based performance patterns.

📈 Metrics Explained
Metric	Description
Spends	Total amount spent on ads
Impressions	Number of times ads were shown
Clicks	Total number of ad clicks
CPC	Average cost per click
CPA	Average cost per acquisition
Link Clicks	Clicks that led to landing pages or external sites
🧮 Analysis Highlights

Google Ads Subchannels

Top spending on Generic and Brand subchannels.

Brand had the lowest CPC, indicating strong brand recall and efficient targeting.

Facebook Ads Device Performance

CPC and CPA were lowest among users aged 45–54.

Suggests better ad relevance for mature audiences.

Combined Data (Ad-data-Assignment-1)

Structured daily campaign records with fields for device type, age, and ad creative.

Enables granular performance analysis.

⚙️ Tools Used

Microsoft Excel / Power BI – Data cleaning and dashboard creation

Python (Pandas / Matplotlib) (optional) – For advanced analytics and automation

🚀 How to Use

Open the Excel file.

Review the Dashboard tab for a high-level view.

Dive into Detail1 and Detail2 for granular performance by platform.

Use filters (e.g., by date, product, or device) to customize insights.

📌 Insights Summary

Google Ads dominates in total spend but with higher CPC.

Facebook Ads performs better in engagement for older demographics.

Desktop devices show consistent CTR across campaigns.

Brand subchannels yield cost-effective conversions.
